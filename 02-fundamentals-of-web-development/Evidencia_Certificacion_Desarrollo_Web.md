# Evidencia del Desarrollo de la Certificación

A continuación, se presentan los aprendizajes clave adquiridos en cada módulo de la certificación en **Desarrollo Web**.

## Módulo 1: Aspectos básicos del desarrollo web
En este primer módulo, se exploraron los fundamentos del desarrollo web y cómo funciona la web a nivel técnico. Aprendimos sobre la arquitectura cliente-servidor, el papel de los navegadores y servidores, y las herramientas principales utilizadas por los desarrolladores. También se introdujo la estructura general de un sitio web y cómo los lenguajes y tecnologías interactúan para dar vida a las páginas web.

## Módulo 2: Desarrollo de sitios para la web
En este módulo, nos enfocamos en la planificación y construcción de sitios web efectivos. Aprendimos sobre las estructuras comunes de páginas web, la navegación y la importancia de un diseño centrado en el usuario. Se trabajó en la organización de contenido, navegación clara y creación de sitios funcionales y accesibles.

## Módulo 3: Introducción a HTML y CSS
Aquí nos adentramos en los lenguajes esenciales del desarrollo web: HTML y CSS. Aprendimos a estructurar el contenido utilizando etiquetas semánticas y a aplicar estilos visuales con CSS. Se desarrollaron habilidades básicas para maquetar páginas web, aplicar colores, tipografías, espaciado y disposición de elementos.

## Módulo 4: Creación de sitios web dinámicos con JavaScript
En este módulo, exploramos JavaScript como herramienta para agregar interactividad a las páginas web. Aprendimos a manipular el DOM, gestionar eventos y aplicar lógica de programación para mejorar la experiencia del usuario. También se introdujeron conceptos como variables, funciones, condicionales y ciclos.

## Módulo 5: Prueba y despliegue de sitios web
Aprendimos cómo garantizar que un sitio web funcione correctamente a través de pruebas funcionales y de usabilidad. Se introdujeron herramientas para identificar errores y se practicó el despliegue de sitios web en servidores públicos. Este módulo fortaleció el conocimiento sobre cómo llevar un proyecto desde el desarrollo hasta su publicación.

## Módulo 6: Desarrollar una página web de lista de tareas
Este módulo fue un proyecto práctico donde aplicamos lo aprendido construyendo una aplicación web de lista de tareas. Se utilizaron HTML, CSS y JavaScript para crear una interfaz interactiva, con funcionalidades como agregar, editar y eliminar tareas, así como almacenamiento local de los datos del usuario.

## Módulo 7: Su futuro en el desarrollo web: el panorama laboral
En el último módulo, analizamos el mercado laboral en desarrollo web. Se discutieron las habilidades más demandadas, las distintas rutas profesionales y cómo construir un portafolio atractivo. También se ofrecieron recomendaciones sobre cómo destacar en entrevistas y posicionarse como profesional en este campo.
